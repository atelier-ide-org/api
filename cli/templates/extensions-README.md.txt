# Icons of the files

One SVG per group of extensions, named after them, joined with `+`: `glb+gltf.svg` is the icon
of every `.glb` and `.gltf` file, in the project tree and the tabs, while the plugin is on. A
`.dark.svg` next to it (`glb+gltf.dark.svg`) is the one of the dark themes. List the same
extensions in `plugin.json` (`"extensions"`).
